# 💼 Salary Prediction App

A Machine Learning based web application that predicts employee salaries based on different input features such as experience, education, job role, and other parameters.  
This project is built using **Python, Machine Learning, Flask, Pandas, NumPy, and Scikit-learn**.

---

## 🚀 Features

- 📊 Predict salary using ML model
- 🧠 Trained Machine Learning algorithm
- 🌐 User-friendly web interface using Streamlit
- 📁 CSV dataset support
- 💾 Saved trained model using Pickle
- ⚡ Fast prediction results

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Pickle
- HTML/CSS
